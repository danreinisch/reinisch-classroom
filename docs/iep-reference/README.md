# IEP Reference Screenshots

This folder contains reference screenshots of IEP (Individualized Education Program) forms used to design the IEP section of the Teacher Center.

## Organization

Upload screenshots grouped by section:

- `plep/` — Present Levels of Educational Performance
- `goals/` — Annual Goals & Short-Term Objectives
- `service-summary/` — Service Summary (related services, frequency, duration)
- `accommodations/` — Accommodations & Modifications
- `transition/` — Transition Planning
- `other/` — Any additional sections

## ⚠️ Privacy Notice

**Do NOT upload screenshots containing student PII (Personally Identifiable Information).**
Redact all student names, dates of birth, ID numbers, and other identifying information before uploading.
