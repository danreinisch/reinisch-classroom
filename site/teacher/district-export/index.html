District Export

Translate Student Code Names (S001, S002…) to real names for district reporting.

🔒 FERPA Privacy Notice: All translation happens entirely in your browser. Real student names are never sent to any server and are never saved to browser storage. Your roster is cleared automatically when you close or refresh this page.

Step 1 — Load Your Student Roster

Upload a CSV file with two columns: code and real_name. Example: S001,Jane Smith. A header row is optional and will be skipped automatically.

📋 Click or drag & drop your roster CSV here
Accepted format: code,real_name (one per line)
⚠️ No roster loaded — upload a roster CSV to enable translation.

Step 2A — Translate Pasted Text or CSV

Paste any CSV data, report text, or narrative content below. All student codes will be replaced with real names.

Step 2B — Translate a File

Upload a .csv, .txt, or .pdf file exported from the platform. A translated copy will be downloaded automatically with student codes replaced by real names.

📄 Click or drag & drop a .csv, .txt, or .pdf file here
A translated copy is downloaded automatically — your original is not modified

Step 3 — Reverse Translate (Names → Codes)

Received district data with real student names? Paste it below to convert names back to Student Code Names (e.g., "Jane Smith" → "S001"). Uses the same roster loaded in Step 1.

Or upload a file with real names — a translated copy will be downloaded automatically with a _coded suffix.

📄 Click or drag & drop a .csv, .txt, or .pdf file here
A coded copy is downloaded automatically — your original is not modified

Tips

  • Use Export for District buttons on the Reporting, Spreadsheet, and Gradebook pages to auto-translate and download directly.
  • The roster is kept in memory only — it is cleared when you close or refresh this page.
  • Translation handles codes embedded in narrative text: "S001 will increase reading skills…" → "Jane Smith will increase reading skills…"
  • Codes are sorted longest-first (S0011 before S001) to prevent partial matches.
  • Your roster is loaded per page. If you navigate to Reporting, Spreadsheet, or Data pages and use their "Export for District" buttons, you'll be prompted to upload your roster again on that page.
  • PDF files are supported — text is extracted from the PDF and translated. The output is a plain text file (not a formatted PDF). Scanned or image-only PDFs without a text layer are not supported; use an OCR tool first or copy the text manually.
