Lock-in checklist (30 seconds)
Say it out loud before the call: clarify → plan → tradeoffs → reliability → outcome.
Clarify requirements + constraints (inputs, outputs, scale, “must not”).
Plan an approach (data structures, API shape, components).
Explain why this path (what you’re optimizing for).
Tradeoffs without prompting (what you’d do differently if X changes).
Reliability (failure modes + mitigations: retries/timeouts, idempotency, observability).
Outcome (result + what changed + how you measured it).
Tip: short is fine — but not vague. Concrete beats confident.
