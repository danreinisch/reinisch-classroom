Schedules and Time — Read It, Record It, Check It
This week: read a work schedule, record clock-in, clock-out, and break times, then correct a simple timecard — 15 points
Big idea: Your schedule says what should happen. Your timecard records what did happen. Check that they agree.

The Weekly Routine

Read → Record → Check

READ the schedule

Find the correct worker, day, start time, end time, and any scheduled break.

RECORD the time

Put clock-in, clock-out, and provided break times in the correct boxes.

CHECK the record

Compare the schedule and timecard. Look for missing, switched, or incorrect entries.

ASK when unsure

Do not invent a time. Ask the supervisor how to correct the record.

Success target: Answer schedule questions, complete a simple timecard, and correct an obvious mismatch using the support level that fits.

Day 2 • Understand the Break

Elapsed Time Is Not Always Work Time

Time from first IN to final OUT
− unpaid break
= recorded work time

Example: 4:00 PM to 8:00 PM is four elapsed hours. If the provided record includes a 30-minute unpaid break, recorded work time is 3 hours 30 minutes.

Use a time chart or calculator when directed. Today’s main skill is placing provided times correctly, not doing difficult time arithmetic.

Day 2 • Do

Complete a Simple Timecard

Your task Use the provided shift information to enter the date/day, clock-in, clock-out, and any provided break times in the correct boxes.

Ready check

  • I used the correct worker and day.
  • IN and OUT are not switched.
  • I recorded the break only when provided.
  • I checked every entry against the source.

Support choices

Color-coded headings, modeled first row, time chart, word bank, calculator, verbal response with teacher recording, or independent completion.

Before you leave: Point to or explain one IN/OUT pair and tell what each time means.

Day 3 • The Check Routine

One Row, One Box at a Time

  1. Confirm the worker and date. A perfect time on the wrong row is still wrong.
  2. Compare the scheduled or provided start with the timecard IN entry.
  3. Compare break entries only when a break is provided.
  4. Compare the provided end with the final OUT entry.
  5. Mark the exact mismatch. Correct it using the workplace procedure.

Do not stare at the whole page and hope the error glows. A fixed sequence reduces missed details.

Day 3 • Error Hunt

What Kind of Error Is It?

The source says Monday IN 4:00 PM. The timecard’s Monday IN box is empty.
The expected information is absent, so this is a missing entry.
The source says Tuesday is OFF, but the timecard shows Tuesday IN 4:00 PM.
Do not guess which record is correct. Identify the mismatch and ask the appropriate person.

Day 3 • Do

Correct the Timecard

Your task Compare the class-provided schedule/shift information with a simple timecard. Mark each mismatch, enter or select the corrected information, and use a professional statement for one error.

Supported response

Match identical times, choose between two corrections, use color coding or a checklist, and read/point to an error-reporting frame.

Independent response

Find all obvious errors, correct them, explain the evidence, and state what should happen if the true time is uncertain.

Teacher evidence: Record accuracy, completion, independence level 0–5, and prompts or supports required.
