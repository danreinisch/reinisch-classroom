✨ New Features

  • Supabase Integration: Fetches students, assignments, submissions, and assignment instances from Supabase when available
  • LocalStorage Fallback: Seamlessly falls back to localStorage when Supabase is not configured
  • Sync Status Indicator: Visual indicator shows current data source (Supabase/Local/Error)
  • Realtime Updates: Automatically refreshes gradebook when new submissions are received (Supabase only)
  • Inline Editing: Score editing now works with both Supabase and localStorage backends
  • Error Handling: Graceful error handling with automatic fallback to local data

🔧 Technical Details

  • Uses existing data-adapter.js pattern for consistency
  • Async/await throughout for clean async operations
  • Compatible with both score (localStorage) and score_total (Supabase) fields
  • Realtime subscription uses debouncing to prevent excessive refreshes
  • Module type script for ES6 import support
