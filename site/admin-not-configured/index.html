Admin Not Configured

The admin uploader is currently disabled because required environment variables are not configured. This is a security feature to ensure the admin interface is only accessible when properly set up.

Required Environment Variables

  • ADMIN_SESSION_SECRET — A random 32+ character string used to sign session cookies (required)

Note: The admin system uses Supabase for authentication. If you need basic authentication instead, you can also configure:

  • ADMIN_USER — Admin username for basic authentication (optional)
  • ADMIN_PASS — Admin password for basic authentication (optional)

How to Configure in Netlify

  1. Go to your Netlify site dashboard
  2. Navigate to Site settings → Environment variables
  3. Add the required variables listed above with appropriate values
  4. For Deploy Preview contexts, ensure variables are scoped to the correct context (Production, Deploy Preview, or Branch Deploy)
  5. Redeploy your site for the changes to take effect

For detailed setup instructions, see the repository documentation or Netlify's Environment Variables Guide.
