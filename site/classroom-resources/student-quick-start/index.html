Student Quick Start.

This is not a tour of every button ReinischClassroom has ever met. It is the map you need to find your work, use the right resources, check what happened, and keep moving.

Step zero

Get into the Student Portal.

1 • Student code

Choose or enter your code

Use your assigned student code. It is how ReinischClassroom knows which work belongs to you.

2 • Password

Enter your password

Use your current password. Keep it private and do not volunteer it to the room like a game-show answer.

Quick check: if the portal already recognizes you, great. If not, student code + password gets you where you need to go.

Graded assignment

Look at the result

A score is information. Feedback is information. Use both.

Important: not every assignment will offer a resubmission. If the button is there, read the feedback before making another attempt.
